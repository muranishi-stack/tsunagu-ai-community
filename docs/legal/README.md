## ⚠️ 公開前に必須の作業

これらは **AI が一般的なマッチング/コミュニケーションアプリの構造に基づいて作成した雛形** です。本番公開前に以下を必ず実施してください。

### 1. 弁護士・行政書士によるレビュー

特に以下の領域はリスクが高く、雛形のまま公開すると **損害賠償・行政指導・ストア審査リジェクト** の対象になる可能性があります。

- 損害賠償の範囲と上限（消費者契約法第8条〜第10条との整合）
- サブスクリプション課金（消費者契約法、特商法、ステルスマーケティング規制）
- 反社会的勢力排除条項
- 個人情報の越境移転（GDPR / 個人情報保護法24条）
- 18 歳未満利用禁止の確認方法（マッチングアプリ規制との整合）

### 3. ストア審査用 URL の用意

App Store / Google Play 申請時には **プライバシーポリシーと利用規約を公開した URL** を提出する必要があります。

ドメイン取得後、以下のような URL でアクセスできるようにしてください。

```
https://tsunagu-ai.app/legal/privacy-policy
https://tsunagu-ai.app/legal/terms-of-service
https://tsunagu-ai.app/legal/tokushoho
```

候補としては:

- **静的 HTML として公開**: Markdown を HTML にレンダーして S3 / Cloudflare Pages / Firebase Hosting 等で配信
- **Flutter Web として公開**: `web/legal/` に HTML を配置して `flutter build web` 時に同梱
- **WordPress / Notion 等の CMS で公開**: 法務担当者が更新しやすい運用

ストア審査担当者から「公開 URL から閲覧できない」と指摘されると審査リジェクトされるため、ドメイン取得・公開ホスティング設定をローンチ前に必ず完了してください。

### 4. アプリ内表示

利用者が新規登録時およびアプリ内設定画面で本文書をいつでも閲覧・確認できるようにしてください。

- 新規登録フロー: 「以下の利用規約とプライバシーポリシーに同意します」のチェックを設置
- 設定画面: 各文書へのリンク（または埋め込み表示）

### 5. App Store / Google Play 申請フォームの記入

申請フォーム内のプライバシー関連項目を埋める必要があります。

- **App Store**: App Privacy Details（Privacy Nutrition Label） — 収集データ、利用目的、紐付けの有無
- **Google Play**: Data Safety Form — 収集データ、共有、目的、暗号化、削除リクエスト方法

本プライバシーポリシーの「1. 取得する個人情報」「2. 利用目的」を参照しながらフォームを埋めてください。
